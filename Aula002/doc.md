# Lista de exercícios #
## **Evolução das Principais Linguagens de Programação** ##

**1 -**
A genealogia das linguagens não é uma escada de progresso porque uma linguagem nova não necessariamente substitui uma antiga. Isso ocorre principalmente pelas necessidades específicas de cada área, como o Fortran na computação científica, e pela influência entre linguagens, já que conceitos antigos podem ser aproveitados na criação de novas linguagens, como aconteceu com o C.

**2 -** Plankalkül é relevante porque apresentou ideias que só seriam usadas em linguagens posteriores, mesmo sem ter sido implementada na época. Três recursos foram estruturas de dados, atribuição e condicionais. A atribuição foi importante por permitir que valores fossem armazenados e modificados durante a execução do programa, conceito básico nas linguagens atuais.

**4 -** O Fortran precisou mostrar que o código traduzido pelo compilador poderia ter desempenho próximo ao código de máquina escrito à mão. Isso era importante porque, apesar de a programação manual ser mais eficiente em alguns casos, era mais cara e demorada. Assim, o Fortran buscava equilibrar desempenho e menor custo de programação, facilitando sua adoção.

**6 -** ALGOL 60 teve grande influência mesmo sem dominar o mercado por trazer contribuições importantes, como blocos e escopo léxico, recursão e uma sintaxe estruturada. Essas ideias influenciaram várias linguagens posteriores. Uma linguagem pode ser muito influente sem dominar o mercado porque suas ideias podem ser aproveitadas por outras linguagens mais utilizadas comercialmente.

**7 -** COBOL foi criada para o processamento comercial, então buscava ser fácil de ler e próxima da linguagem usada pelos profissionais da área. Seus registros foram estruturados para representar dados comerciais, como funcionários e transações. Além disso, COBOL recebeu forte influência da FLOW-MATIC, principalmente na preocupação com legibilidade e no processamento de registros.

**12 -** Uma pequena base Prolog poderia ter os fatos: “João é pai de Ana” e “Ana é mãe de Pedro”. A regra seria: “Se alguém é pai de uma pessoa e essa pessoa é mãe de outra, então ele é avô dessa outra pessoa”. A consulta poderia ser: “João é avô de Pedro?”. Isso representa programação lógica porque o programa define fatos e relações e usa regras para deduzir novas informações, em vez de apenas armazenar dados.

**13 -**. Ada foi projetada para sistemas críticos, por isso priorizou confiabilidade e segurança. Seus tipos e pacotes ajudam a organizar e controlar o código, enquanto a concorrência permite lidar com várias tarefas simultaneamente, algo importante em sistemas de grande escala.

**15 -** Java foi criada inicialmente para aplicações em dispositivos, mas acabou ganhando espaço com o crescimento da Web. Isso mostra que uma linguagem pode ser reposicionada por mudanças no contexto tecnológico, passando a ser usada em domínios diferentes daquele para o qual foi originalmente criada.

**16 -** As linguagens de scripting possuem características diferentes. Perl surgiu para processamento de texto e manipulação de arquivos; JavaScript, para scripts em páginas Web; PHP, para desenvolvimento Web; Python, como linguagem de propósito geral com estruturas de dados flexíveis; Ruby, com foco em programação orientada a objetos; e Lua, voltada principalmente para extensão e incorporação em outras aplicações. Elas também diferem na implementação, usando principalmente interpretação, embora algumas utilizem compilação ou máquinas virtuais.

**18 -** XSLT recebe documentos XML como entrada, transforma seus dados e gera outra estrutura, geralmente XML ou HTML. JSP recebe páginas com marcação e código Java, processa esses elementos no servidor e gera HTML como saída. Ambas são híbridas porque combinam marcação com recursos de programação para realizar processamento e gerar uma saída.
